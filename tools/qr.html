QR Code Generator

💡 Good to know

  • Use the SVG download for anything printed — it stays sharp at any size.
  • Higher error correction makes the code denser but more tolerant of a smudge or a logo on top.
  • Keep dark modules on a light background — inverting the colours confuses many scanners.
  • Nothing is uploaded; the code is generated locally so it works offline.
