🚀 Skills

Real skills you can start from zero — each with a simple roadmap and free resources.

💻 Web Development 3–6 months

Build websites and web apps. The highest-demand skill in the world right now.

  1. HTML — structure of every website (1–2 weeks)
  2. CSS — design and layout (3–4 weeks)
  3. JavaScript — make things interactive (2–3 months)
  4. Build 3 real projects: portfolio, tool site, game
🆓 Free: freeCodeCamp, MDN Web Docs, YouTube (Traversy Media)

🎨 Graphic Design 1–3 months

Logos, posters, social media designs. Start earning from day one with Canva.

  1. Learn Canva (free) — 1 week to basics
  2. Study colour theory and typography (2 weeks)
  3. Learn Figma — the free pro tool for UI design
  4. Recreate 10 designs you admire, then make your own
🆓 Free: Canva Design School, Figma Academy, YouTube

📊 Excel / Spreadsheets 2–6 weeks

Every office job needs this. Formulas, charts, pivot tables — see the Formulas page.

  1. Basic formulas: SUM, AVERAGE, IF, VLOOKUP
  2. Charts and conditional formatting
  3. Pivot tables — analyse data in minutes
🆓 Free: ExcelJet, Microsoft Learn, YouTube (Leila Gharani)

🗣️ English Speaking ongoing

The world's connective language. Daily 20 minutes beats weekend cramming.

  1. Learn 10 new words daily with example sentences
  2. Shadow native speakers — repeat after YouTube/podcast audio
  3. Speak to yourself 10 minutes a day (really works)
  4. Find a language partner online for weekly practice
🆓 Free: BBC Learning English, YouTube (EngVarta), Duolingo

🎬 Video Editing 1–2 months

Content creators are the new TV. Every business wants video now.

  1. Start with CapCut (free, phone) — cuts, transitions, text
  2. Learn DaVinci Resolve (free, PC) — the pro standard
  3. Study pacing: watch ads and note when scenes change
  4. Edit 5 videos for friends free — build a portfolio
🆓 Free: DaVinci Resolve, CapCut, YouTube tutorials

📱 Content Creation ongoing

TikTok, YouTube, Instagram — learn to hook attention in 3 seconds.

  1. Pick one niche and one platform — go deep, not wide
  2. Post 30 videos before judging results
  3. Study your top 3 performers and make more like them
🆓 Free: your phone + consistency is the whole stack
